## 迁移指南

### 如果你之前使用 `get-upgrade-tasks`：

**旧方式:**
```
POST /device-maintenance:get-upgrade-tasks
{
  "batchId": "xxx"
}
```

**新方式:**
```
POST /device-maintenance:get-device-tasks
{
  "batchId": "xxx",
  "taskType": "UPGRADE"  // Optional: 只看升级任务
}
```

**注意响应格式变化:**
- 旧: `{ "success": true, "data": [...] }`
- 新: `{ "success": true, "data": { "tasks": [...], "totalCount": 100, "page": 0, "size": 10 } }`
